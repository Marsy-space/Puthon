# Лабораторная работа 2. Консольное приложение "Студенты и оценки" (CSV)

## Структура проекта

```
project_root/
  lab/
    __init__.py
    errors.py        # собственные исключения
    models.py        # класс Student + валидация полей
    io_utils.py       # чтение/запись CSV
    processing.py     # CRUD, сортировка, фильтрация, статистика, ТОП-N
    main.py            # CLI меню, точка входа
  data/
    students.csv       # пример входного файла
  tests/
    conftest.py
    test_models.py
    test_io_utils.py
    test_processing.py
    test_main_cli.py
  pytest.ini
  requirements-dev.txt
  README.md
```

## Установка pytest

1. Убедитесь, что установлен Python 3.9+: `python3 --version`
2. Установите зависимости для разработки:
   ```
   pip install -r requirements-dev.txt
   ```
   или напрямую:
   ```
   pip install pytest
   ```
   (если у вас несколько версий Python, используйте `pip3 install pytest` или `python3 -m pip install pytest`)

## Запуск приложения

Из корня проекта (`project_root/`):

```
python -m lab.main
```

Дополнительные (необязательные) аргументы командной строки:

```
python -m lab.main --load data/students.csv          # загрузить файл сразу при старте
python -m lab.main --load data/students.csv --top 3   # показать ТОП-3 и выйти
python -m lab.main --save out.csv                     # сохранить список в файл при выходе из меню
```

## Запуск тестов

Из корня проекта:

```
pytest -q
```

## Пункты меню

1. Загрузить студентов из CSV
2. Сохранить студентов в CSV
3. Показать всех студентов
4. Добавить студента
5. Удалить студента по id
6. Обновить оценки студента по id
7. Показать статистику по группе (кол-во, общий средний, лучший/худший)
8. Экспортировать ТОП-N студентов в CSV
9. Отсортировать и показать (avg / name / id)
0. Выход

## Формат CSV

```
id,name,grade1,grade2,grade3
1,Иванов Иван,78,85,90
2,Иванов Петр,65,70,0
...
```

- Заголовок необязателен — если первая ячейка первой строки похожа на число,
  файл считается файлом без заголовка.
- Пустая ячейка с оценкой = отсутствующая оценка (не участвует в расчёте среднего).
- Кодировка файлов — UTF-8.

## Сайт (только просмотр, раздача через CDN)

Сайт `site/index.html` статичный и **не может менять данные**: он только читает
`site/data.json` и сам обновляется, когда этот файл изменился.

Схема: `CSV / CLI  ->  python -m lab.publish  ->  site/data.json  ->  CDN  ->  браузер`

1. Меняете данные (CSV или через `python -m lab.main`, пункт 2 "Сохранить").
2. Публикуете: `python -m lab.publish --csv data/students.csv --out site/data.json`
   (файл перезаписывается только если данные реально изменились).
3. Загружаете папку `site/` на CDN / статичный хостинг (GitHub Pages, Netlify, Cloudflare Pages и т.п.).
4. Открытые страницы раз в 30 секунд проверяют `data.json` (условный запрос, при отсутствии
   изменений приходит короткий ответ 304) и перерисовываются, только если изменился `version`.

Локальный просмотр (из папки `site/`): `python -m http.server 8000`, затем http://127.0.0.1:8000/
(через двойной клик по файлу не заработает: браузер блокирует fetch с file://).
